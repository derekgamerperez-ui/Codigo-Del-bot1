# 🤖 Bot de Discord con Inteligencia Artificial

## 📌 Descripción

Este proyecto consiste en un bot de Discord desarrollado en Python que busca integrar inteligencia artificial para clasificar imágenes mediante un modelo previamente entrenado.

El proyecto utiliza `discord.py` para la interacción con Discord y un modelo de aprendizaje automático para procesar las imágenes enviadas por los usuarios.

## ✨ Características

- 🤖 Integración con Discord.
- 🧠 Clasificación de imágenes mediante inteligencia artificial.
- 🐍 Desarrollado en Python.
- 🚧 Comando `!check` actualmente en desarrollo.

## 🚧 Estado del proyecto

**El proyecto está en desarrollo.**

Actualmente, el comando `!check` no funciona correctamente debido a problemas de funcionamiento relacionados con la integración con Discord. Se está trabajando para identificar y solucionar el problema.

Las demás funcionalidades podrán desarrollarse y mejorarse a medida que avance el proyecto.

## 🛠️ Tecnologías utilizadas

- Python
- discord.py
- Keras
- Modelo de clasificación de imágenes

## 🎯 Objetivo

Crear un bot de Discord capaz de recibir imágenes y utilizar inteligencia artificial para clasificarlas automáticamente, ofreciendo los resultados directamente en el servidor.

🚀 Este proyecto continúa en desarrollo y se actualizará a medida que se implementen mejoras y soluciones.
